# Bundle the restic binary inside the Flatpak

The app shells out to `restic --json` as its only integration with restic (no stable Rust binding exists). Since the app ships as a Flatpak, it needs a way to invoke restic from inside the sandbox: either `flatpak-spawn --host restic` (uses whatever restic is installed on the host, needs `--talk-name=org.freedesktop.Flatpak`) or compiling/vendoring restic as a Flatpak build module. We chose to bundle restic in the Flatpak manifest, following the precedent set by Pika Backup (same category: GTK4/Rust/libadwaita wrapper around a backup engine), which bundles BorgBackup the same way. This avoids depending on the host having restic installed or on the sandbox-escape permission `flatpak-spawn --host` requires, at the cost of the project needing to track and update the vendored restic version itself.
